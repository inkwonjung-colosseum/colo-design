UI/UX 개선안 목업 · 2026-09-16

Colo Design, 대화 도구로 다시 입히기

현재 UI는 콘솔에서 출발한 차가운 판넬 구조입니다. 개선안은 채팅형 디자인 도구의 언어를 빌립니다 — 따뜻한 종이색, 세리프 제목, 둥근 카드, 그리고 대화가 언제나 화면의 주인공인 배치. 각 목업은 실제 화면 구조(사이드바 트리 · 대화 열 · 미리보기 패널 · 사이클 바)를 그대로 옮긴 것입니다.

작업 공간 — 대화 + 미리보기
말한 것 → 돌아온 화면 카드 → 오른쪽 라이브 미리보기. 사이클 바가 저장·넘기기를 상단에 둡니다.
새 대화 — 빈 상태
빈 대화는 가운데 정렬 히어로 + 큰 입력창 + 제안 칩. "무엇을 만들지"만 묻습니다.
턴 진행 중 — 도구·큐·중지
도구 호출은 접힌 한 줄, 대기 메시지는 입력창 위 칩, 보내기 버튼은 중지로 바뀝니다.
온보딩 — 첫 실행 마법사
CLI 확인 → 로그인 → 레포 선택을 세 단계 카드로. 막힌 단계만 색을 입힙니다.
설정 — 대화·미리보기·알림
항목은 이름+설명+컨트롤 한 줄씩. 테마 타일은 실제 팔레트를 입은 미리보기.
명령 팔레트 — ⌘K
대화·화면·프로젝트·설정을 한 검색창에서. 선택 행은 액센트 소프트로.
컴포넌트 시트 — 디자인 토큰
버튼·칩·도구행·알림·스위치 등 개선안의 부품 전체를 한 장에.

화면 구성 재설계 — 4모델 제안 종합

GLM-5.3 · GLM-5.3-Flash · SWE-2 · Sonnet-5가 각자 낸 구성안 → 교차 비평 → 여정 심문 2라운드로 확정한 수정 8건 반영. 근거: docs/layout-redesign-synthesis.md

최종안 — 지금 / 작업 / 시작
세 얼굴이 실제로 전환됩니다. 사이클 바는 전폭 머리 줄로 올라갔고, 카드는 사건의 주인을 따라갑니다.
지금 — 피드 홈 (권고안)
나를 기다리는 일이 창의 현관. 레일 존치, 칩은 프로젝트 것, 허가 승인은 대화 안에서만.
1단계 — 레일 「지금」 행
가장 싼 첫 조각: 트리 맨 위 고정 행 + 팝오버. 새 데이터 없음, 행 삭제로 완전 원복.
비교안 — 화면이 몸통 (보류)
미리보기가 1fr, 대화가 오른쪽 날개. 심판 불일치 항목 — 실측 게이트 뒤 결정.

git 여정 재설계 — 토큰에서 PR까지, 5안

terminal/git을 모르는 사람이 토큰만으로 연결→만들기→저장→넘기기→반영까지 가는 화면 구성 대안. 근거: docs/gitflow-layout-proposals.md · 권고: 1+5 조합

안 1 — 다음 할 일 (권고)
git 여정 전체가 라벨이 바뀌는 한 버튼. 대화/미리보기는 토글로 한 번에 하나.
안 2 — 만들기/보내기 두 개의 방
보내기 방은 우체국: 포장(저장) → 발송(넘기기) → 배달 추적(검토·반영).
안 3 — 프로젝트 일기
git log를 시간축 문장으로. "저번에 뭐 했더라"가 스크롤로 답되는 프로젝트 홈.
안 4 — 화면 보드
제품의 화면이 목차. 상태 칩이 화면 카드에 붙고, 저장·넘기기는 프로젝트 띠에.
안 5 — 첫 사이클 마법사 (권고)
토큰→레포→첫 화면→넘기기까지 4장의 전면 안내. 첫 반영 후 해체.

클린 룸 3안 — Claude chat만 아는 사용자

기존 자료를 차단한 채 세 모델이 독립 수행. 전제: 사용자의 유일한 UI 문법은 대화 목록·스크롤·입력창·artifact 패널. 근거: docs/fresh-layout-proposals.md · 권고: chat 골격 + journey의 검토-중 장면 이식

fresh-chat — 대화가 전부 (GLM-5.3-Flash)
새 화면 0개. 미리보기는 대화에서 열리는 패널, 저장·넘기기·반영은 대화 안 카드와 타임라인.
fresh-product — 제품이 주인공 (GLM-5.3)
창 전체가 만든 화면, 대화는 하단 시트. 상태는 미리보기 크롬에 문서앱 문법으로.
fresh-journey — 여정이 구조 (SWE-2)
연결→만들기→검토 중 세 장면. 전환은 스테퍼가 아니라 버튼 클릭이 일으킨다.

최종안 — 대화가 전부 + 검토 중 장면 이식

fresh-chat 골격에 fresh-journey의 검토-중 장면(동결 스냅샷·코멘트 메시지·답장 채널)을 이식. 모달은 앱 자체에 관한 것만 남기고 나머지는 대화 안 카드로.

시작 — 토큰 → 레포
대화가 아직 시작되지 않은 첫 메시지. 토큰 붙여넣기 → 같은 자리에서 레포 고르기.
작업 중 — 저장 제안
Claude chat 그대로 + 대화 안 저장 카드 + 입력창 위 "저장 안 한 변경" 칩.
검토 중 — 보낸 화면 동결
미리보기가 "보낸 화면" 스냅샷으로 잠기고, 개발자 코멘트가 대화에 메시지로 도착.
반려 — 사유와 되돌아가기
반려 사유가 대화에 도착. "수정하러 가기"가 작업 상태로 되돌리는 유일한 버튼.
모달 — 남는 것들만
설정·토큰 만료·저장 안 하고 끄기·대화 삭제·단축키. 저장 검토·넘기기·코멘트는 대화 안 카드로.

대화 우선
내 말은 둥근 말풍선, 답변은 말풍선 없는 산문. 도구 호출은 기본 접힌 한 줄 — 대화가 스크롤을 이깁니다.
둥근 형태
카드 20px, 입력창 28px, 칩·버튼은 pill. 헤어라인은 옅게, 구분은 여백으로.
사이클 바
쓰기→만들기→검토→저장→넘기기 진행을 미리보기 상단의 스텝 바로. 다음 행동 버튼이 같은 줄에.
