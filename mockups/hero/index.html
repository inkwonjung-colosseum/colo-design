최고의 화면 — 네 장면

같은 브리프("이 앱의 정점이 되는 화면 하나")를 네 모델이 서로 다른 출발점에서 그렸습니다. 넷은 경쟁 관계가 아니라 한 앱의 네 장면입니다 — 돌아왔을 때(home) → 일하는 중(chat) → 지금 어디인지(journey) → 결과물에 몰입(product).

home — 돌아왔을 때가 정점

3시간 비우고 돌아온 순간. "뭐 만들까"가 아니라 "뭐가 나를 막고 있나"의 인박스 — 결정 필요 카드(질문 인용+즉답 칩) → 진행 중 → 방금 있던 일. 3단계 알림 위계.

sonnet-5 · Orca Agents feed · Antigravity Inbox · amux

chat — 대화가 정점

개발자 검토 결과가 메시지로 도착한 직후. 반려조차 새 화면이 아니라 답장 한 번 — 화면 카드·상태 카드·진행 한 줄·사람 메시지. Claude chat 문법 그대로.

glm-5.3-flash · Claude Desktop 페인 · Maestro Concerto

journey — 여정이 정점

여정 전체를 통과하는 순간. 상단 지도(연결→만들기→저장→넘기기→반영)가 "지금 어느 장면인가"를 말하고, 장면 전환은 사용자의 버튼이 일으킨다.

swe-2 · Conductor Checks 번역 · 동결 스냅샷

product — 제품이 정점

방금 나눈 말이 실제 앱 화면에 도착하는 순간. 미리보기가 창의 97%, 대화는 접히는 층, 문서앱 제목바(바꿈6·저장 안 됨), 고침 표시↔핀 1:1.

glm-5.3 · Orca Design Mode · Factory 포인트-앤-코멘트

권고 조합

문 = home
앱을 열면 인박스. 카드 클릭 = 그 대화로 착지.
작업면 = chat + journey 띠
대화가 주인공, 상단에 읽기 전용 여정 지도. 미리보기 패널 제목바는 문서 문법.
몰입 = product
미리보기 "크게 보기"가 전체화면+오버레이 시트로 확장. 기본값 아님.
넘긴 후 = journey 동결
'보낸 화면' 스냅샷 + 개발자 코멘트는 대화에 메시지로.
