비개발자를 위한 화면 만들기 도구

말과 문서가
화면이 됩니다

개발 지식이 전혀 없는 사람이 — 기획자든 디자이너든 사업·운영 담당자든 — 작업할 서비스의 저장소를 연결하면, 그 안에서 도는 AI 세션이 말을 화면으로 만들어 줍니다. git이나 터미널을 몰라도 씁니다.

앱 내려받기 초대장 만들기

작업은 한 바퀴로 흘러갑니다

  1. 말하기 만들고 싶은 화면을 말로 보냅니다. 참고 그림이나 문서 파일을 함께 붙여도 됩니다.
  2. 미리보기 그 서비스의 앱을 그대로 띄운 화면에서 결과를 확인합니다. 고칠 곳은 핀으로 찍어 보냅니다.
  3. 제출 완성되면 제출 한 번 — 도구가 안전하게 묶어 개발자에게 요청으로 보냅니다.
  4. 반영됨 개발자가 합치면 상태 칩이 반영됐어요가 되고, 다음 작업은 새 사이클입니다.

브랜치 · 커밋 · 푸시 · 풀 리퀘스트 같은 말은 도구가 대신 다룹니다. 저장이라는 말도 없습니다 — AI가 한 차례 답할 때마다 도구가 스스로 그 시점을 보관합니다.

설치

  1. 릴리스 페이지에서 기계에 맞는 파일을 내려받아 설치합니다 — mac은 colo-design-<버전>-mac-arm64.dmg, Windows는 colo-design-Setup-<버전>-win-x64.exe.
  2. 첫 실행에 한 번 허가가 필요합니다 — mac은 앱을 우클릭 → 열기, Windows는 SmartScreen의 추가 정보 → 실행.
  3. 준비물은 둘입니다 — 화면을 만드는 AI 에이전트 하나(Claude Code · Codex 중 설치하고 로그인한 것)와 git. 실행에 필요한 런타임은 앱에 들어 있습니다.
  4. 개발자가 보내 준 초대 파일(*.colo-invite)을 시작 화면에서 열거나 창에 끌어다 놓으면 연결 코드 저장과 프로젝트 만들기가 한 번에 끝납니다.

초대장 만들기 개발자용

사용자에게 보낼 초대 파일(*.colo-invite)을 만듭니다. 파일에는 연결 코드가 들어 있으니 사용자만 보는 경로(슬랙 DM 등)로 보내고, 가져오기가 끝나면 지우라고 안내하세요. 입력한 값은 이 브라우저 안에서만 쓰입니다 — 어디에도 전송되지 않습니다.
