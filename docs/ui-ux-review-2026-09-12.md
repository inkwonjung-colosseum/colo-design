# Colo Design UI/UX 종합 평가 — 2026-09-12

**방법.** 실제 렌더링 스크린샷 7종(메인 워크스페이스·사이드바·넘기기·온보딩 2종·설정 다크/라이트)과
웹 패키지 전체 소스(styles.css 6,432줄 포함)를 4개의 독립된 전문 에이전트가 서로 다른 렌즈로 평가했다.
접근성 에이전트는 17개 테마 × 22개 색 쌍 = **374개 조합의 WCAG 2.1 대비율을 상대 휘도 공식으로 직접 계산**했고,
카피 에이전트는 **한국어 문자열 537개 라인을 수집·빈도 대조**했다. 이 문서의 모든 파일:줄 번호는 본 검증을 거쳤다.

| 렌즈 | 점수 | 한 줄 평 |
|---|---|---|
| 시각 디자인 | **6.0 / 10** | 시스템(토큰·게이트·모티프)은 시니어급인데 타이포에서 무너지고 상태 칩 매핑이 틀어졌다 |
| UX 플로우 | **7.5 / 10** | 성공 경로의 설계 밀도는 동급 최상위, 실패 경로·발견성에서 약속이 스스로 무너진다 |
| 접근성·테마 | **6.5 / 10** | 구조적 ARIA·포커스 트랩은 상용 수준, 색 정량 검증에서 79개 페어 탈락 |

## 강점 — 고칠 때 절대 건드리지 말 것

- **인크(잉크색) CTA**: `.primary`는 액센트가 아니라 `--text` 배경이다(styles.css:816-832). 전 17테마 대비 통과. 옳은 결정.
- **램프 도트 모티프**: 상태를 단어가 아니라 빛으로 — `box-shadow` 3px 링(styles.css:4156-4163). 아이디어가 좋다(매핑만 고치면 된다).
- **구조적 접근성**: 완전한 포커스 트랩+복원(use-modal-focus.ts), combobox 완결(Palette), IME 조합 처리(Composer.tsx:518), `prefers-reduced-motion` 전역 킬스위치+8개 로컬 블록, ⌘K/⌘T/⌘,/⌘/로 저장→넘기기 사이클 키보드 완결.
- **카피 기계**: 상태 칩 6종 상수화(delivery.ts), 도구명·게이트명 번역 사전(tool-names.ts), "실패+다음 행동" 오류 문형.
- **라디 토큰 5단계(4/6/8/12/16), lucide 단일 스트로크 게이트, 17테마 토큰 완전 재정의(누락 0)**.

## P0 — 즉시 수정 (합의 필요 없는 결함)

### P0-1. 키보드 포커스 링이 모든 폼 입력에서 소멸한다
- **근거**: styles.css:793-796 `input:focus, textarea:focus, select:focus { outline: none }`는 특이도 (0,1,1)으로
  styles.css:811 `:focus-visible` (0,1,0)의 2px 링을 이긴다. 남는 신호는 보더색 변화뿐인데 `--line→--line-hover`의
  대비 변화는 테마별 **1.20~2.94:1**로 WCAG 2.4.11에 크게 미달.
- **영향**: 설정의 레포 주소·GitHub 토큰·이름 바꾸기 등 모든 폼에서 키보드 사용자가 위치를 추적할 수 없음.
- **권장**: 793행 선택자를 `input:focus-visible, textarea:focus-visible, select:focus-visible`로 바꾸고,
  811행의 링은 65% 알파를 제거해 불투명 `2px solid var(--accent)`로(밝은 테마에서 65% 링은 1.91~2.73:1로 3:1 미달 — 계산 검증됨).

### P0-2. "기획자는 PR을 읽지 않는다"는 약속이 정확히 설명의 자리에서 깨진다
- **근거**(모두 실측 인용):

  - `delivery.ts:120,139` `이미 넘겼습니다 — 저장하면 같은 PR 에 쌓입니다`
  - `delivery.ts:149` '저장됨' 칩 툴팁 = **원시 브랜치명**(`colo-design/20260912-3`)
  - `RepoPicker.tsx:379` 첫 화면 확륜 문구 `✓ colo-design.json 있음 · 기본 브랜치 ${defaultBranch}`
  - `RepoPicker.tsx:383,442` `PR은 열지 못합니다`, `첫 넘기기 PR 로 받아 봅니다`
  - `ScreenPanel.tsx:744` 매 턴 토스트 `` `Claude 는 ${title} 를 고쳤습니다.` `` — '를'이 앞 단어와 띄어진 비문 + 받침 무시('화면' 뒤엔 '을'; `objectParticle()` 헬퍼가 tool-names.ts:12에 이미 있는데 미적용)
- **권장 문안**: `저장하면 넘긴 요청에 함께 담깁니다` / `저장됨` 툴팁은 `이번 저장은 아직 개발자에게 전달되지 않았습니다`(또는 툴팁 제거) /
  첫 화면은 `✓ 화면 제작 준비가 된 레포입니다` / 토스트는 `Claude가 ${objectParticle(title)} 고쳤습니다.` 형태로.

### P0-3. 상태 칩 시맨틱 매핑 — 여섯 상태가 네 색이고, 유실 위험이 무채색이다
- **근거**: styles.css:4165-4184. `저장 안 함`=`--text-2`(무채색), `저장됨`=`--ok`, `반영됨`=`--ok`(**동일색**), `개발자 검토 중`=`--accent`, `변경 요청`=`--danger`.
- **문제**: ① 가장 행동을 재촉해야 할 "저장 안 함 N건"이 "변경 없음"과 구분되지 않는다. ② 로컬 저장(저장됨)과 머지 완료(반영됨)는
  다른 단계인데 같은 초록이라 사이클의 종착점을 알 수 없다. ③ 칩 라벨의 `#5` 식별자(delivery.ts:115)는 기획자에게 무의미하다.
- **권장**: 저장 안 함 → `--warn` + warn-line 보더. 저장됨 → `--ok` 70% 틴트(또는 램프만 ok, 텍스트는 text-2). 반영됨 → 램프를
  lucide Check 10px로 교체(머지 완료 = 체크). 여섯 상태 = 여섯 시각적 위치. 칩 라벨에서 `#N` 제거(번호는 툴팁으로).

### P0-4. 타이포그래피 스케일 부재 — 12단계·0.5px 난립, 한글에 네거티브 트래킹
- **근거**: styles.css 전역에서 9, 9.5, 10, 11, 11.5, 12, 12.5, 13, 13.5, 14, 15, 16px 공존(977~5083행).
  `-0.012em` 등 네거티브 트래킹이 `.empty__lead`, `.modal__title`, `.planner__project` 등 **한글 위계 텍스트**에 적용.
  letter-spacing 값은 11종. 9px는 `content: "▸"` 글리프(icons.tsx가 선언한 lucide 게이트 위반), 9.5px 모노 대문자 라벨은 자체 주석이 "콘솔 취향이라 버렸다"고 한 패턴의 잔재.
- **문제**: 7px 범위에 12단계는 지각 불가능한 차이로 리듬만 어긋뜨리고, 반픽셀은 서브픽셀 렌더링을 흐리게 한다. 한글 음절 블록에
  라틴 디스플레이 관행(타이트 트래킹)을 걸면 조밀하고 답답하다. Pretendard는 한글 트래킹 0 전제 설계다.
- **권장**: 스케일 5단계 강제 — 11 / 12 / 13 / 15 / 17(히어로 22). 12.5→13, 13.5→13|15, 11.5→11|12로 반올림, 0.5px 전면 금지.
  트래킹 토큰 3개 — 한글 0, 라틴·숫자 디스플레이 -0.01em, 오버라인 +0.05em. `▸` → lucide ChevronRight 12px.

### P0-5. 실패 상태에서 원본 기계 출력이 한국어 설명 없이 노출된다
- **근거**: `HandoffPanel.tsx:142-146` — 게이트 실패 시 `<pre><code>{detail}</code></pre>`를 접기 없이 직접 렌더.

  `daemon/onboarding.ts:87` — "데몬 환경에서 키를 제거하고 다시 시작해 주세요"(헤더에서 '데몬'을 지운 것과 정반대).
- **문제**: 비개발자의 첫 실패 경험이 공황 포인트가 된다. 같은 제품에서 `DiffPanel.tsx:323-330`은 원시 출력을 "자세히" 폴드 뒤에 감추는데 여기는 덤프한다 — 불일치.

### P0-6. latte 등 공식 팔레트 그대로 가져온 테마 — 선택 자체가 접근성 저하

- **권장**: UI 상태용 파생색 계층 추가(예: latte accent #7287fd→#1e66f5 4.6:1, warn #df8e1d→#946200, ok #40a02b→#197a00).
  원본 팔레트 색은 코드 하이라이트 등 장식용으로 남긴다. 하드코딩된 select 화살표 #898b96(styles.css:805, 토큰을 무시하는 유일한 색)은 mask 패턴으로 토큰화.

## P2 — 개선

- **선택 상태 토큰 이원화**: `--select-bg` 알파 0.25 vs 온보딩 카드 선택 `--accent-soft` 0.09(모니터 밝기에 따라 사라짐) → 단일 토큰(0.18-0.22 틴트 + 1px 액센트 보더) 통일, 카드형 선택은 틴트·보더·라디오 마크 3신호 중 최소 2개.
- **상태 칩 틴트 6% + 도트 6px**: 시맨틱 색이 11.5px 텍스트에만 실림 → 틴트 10-12%, 도트 7px(P0-3과 함께).
- **채팅 헤더에 상태 미러링**: 칩이 미리보기 칼럼에만 있어 좁은 창(사이드바 1100px에서 접힘)에서 "저장 안 함"이 시야 밖 → 채팅 헤더에 미니 상태 점 + 건수.
