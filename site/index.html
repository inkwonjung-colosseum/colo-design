한 바퀴

작업은 한 바퀴로 흘러갑니다

상태 줄의 여정 세 점이 지금 어디쯤인지 말해 줍니다 — 판정은 전부 기계적 신호라 사람이 임의로 바꿀 수 없습니다.

제출 전 개발자 확인 반영됨
  1. 01 말하기 만들고 싶은 화면을 말로 보냅니다. 참고 그림이나 문서 파일을 함께 붙여도 됩니다.
  2. 02 미리보기 · 찍기 서비스의 앱이 그대로 뜬 화면에서 결과를 확인합니다. 고칠 곳은 ⌥+클릭으로 찍어 말풍선을 남깁니다.
  3. 03 제출 완성되면 제출 한 번 — 확인 한 장이 뜨고, 도구가 묶어서 개발자에게 요청으로 보냅니다. 개발자의 코멘트는 AI가 바로 반영해 다시 제출합니다.
  4. 04 반영됨 개발자가 합치면 셋째 점이 반영됐어요가 되고, 반영된 내용은 도구가 스스로 받아 옵니다. 다음에 만드는 것은 새 작업입니다.

저장이라는 말도 없습니다 — AI가 한 차례 답할 때마다 도구가 스스로 그 시점을 보관하고, 작업 기록 서랍에서 언제든 그 시점으로 되돌아갈 수 있습니다.

설치

  1. 릴리스 페이지에서 기계에 맞는 파일을 내려받아 설치합니다 — mac은 colo-design-<버전>-mac-arm64.dmg, Windows는 colo-design-Setup-<버전>-win-x64.exe.
  2. 첫 실행에 한 번 허가가 필요합니다 — Windows는 SmartScreen의 추가 정보 → 실행, mac은 시스템 설정 → 개인정보 보호 및 보안 → 확인 없이 열기.
  3. 첫 화면은 마법사가 아니라 체크리스트 한 장입니다 — 도구 준비 · AI 연결 · 초대 파일. Claude Code 는 설치 버튼 하나로 사용자 폴더에 깔리고, 로그인은 브라우저에서 본인 계정으로 마치면 저절로 넘어갑니다. 터미널은 끝까지 열지 않습니다. Codex 는 선택입니다.
  4. 초대 파일(*.colo-invite)을 창에 놓으면 끝입니다 — 연결 코드 저장과 개발자가 고른 프로젝트 전부의 설정이 한 번에 끝나고 첫 프로젝트가 열립니다. 앱과 AI의 업데이트는 설정의 업데이트 줄이 저절로 확인합니다.

첫 화면은 체크리스트 한 장

  • 도구 준비앱이 싣고 온 도구를 확인합니다
  • AI 연결설치 버튼 → 브라우저에서 로그인
  • 초대 파일받은 파일을 창에 놓습니다

셋이 다 채워지면 작업 화면으로 넘어갑니다 — 시작하기 버튼은 없습니다

개발자용

초대장 만들기

연결 코드를 넣고 레포를 고르면, 고른 레포 전부가 초대 파일 하나에 실립니다 — 사용자는 파일을 놓기만 하면 모든 프로젝트가 설정됩니다. 내려받은 파일의 내용은 앱만 읽을 수 있게 가려집니다 — 편집기로 열면 알아볼 수 없는 글자로 보입니다. 그래도 연결 코드가 들어 있으니 사용자만 보는 경로(슬랙 DM 등)로 보내고, 가져오기가 끝나면 지우라고 안내하세요. 입력한 값은 이 브라우저 메모리에만 두고, 요청은 GitHub에만 보냅니다. 나중에 레포를 더 붙이거나 리뷰어를 바꿀 때도 새 초대 파일을 보내면 됩니다 — 사용자는 앱 어디에나 끌어다 놓거나 설정 → 연결 → 초대 파일 열기로 받습니다.

    고른 프로젝트

    고른 순서가 초대장 순서입니다 — 첫 프로젝트가 사용자에게 먼저 열립니다.

    주소로 직접 추가 조직이 승인하지 않은 세밀한 권한 코드는 목록에 레포가 안 보일 수 있어요 — 그럴 때 주소로 넣어 주세요.
    개발자 알림 (Slack, 선택)

    문제가 생겼을 때 도구가 개발자를 부르는 길입니다 — 저장소에 알림을 남길 수 있는 연결 코드면 비워도 됩니다.

    이메일로 보내기

    이메일은 메일 앱에 초안을 엽니다 — 내려받은 파일을 첨부해 보내세요. 공유하기는 OS가 파일 공유를 지원할 때만 나타나며, 슬랙 같은 앱으로 파일을 바로 넘깁니다.
