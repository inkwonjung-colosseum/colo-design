한 바퀴

말하고 · 찍고 · 제출

할 일은 딱 세 가지예요. 상태 줄의 세 점이 지금 어디쯤인지 말해 주고, 판정은 전부 기계적 신호라 사람이 임의로 바꿀 수 없어요.

제출 전 개발자 확인 반영됨
  1. 01 말하고 원하는 화면을 말로 보내요. 참고 그림이나 기획 문서를 끌어다 놓아도 돼요.
  2. 02 찍고 고칠 곳은 설명 대신 ⌥ Option + 클릭 (Windows 는 Alt). 그 자리에 메모가 붙어요.
  3. 03 제출 다 됐으면 버튼 하나. 확인 한 장을 거쳐 개발자에게 바로 가고, 개발자의 코멘트는 AI 가 바로 반영해 다시 제출해요.
  4. 04 반영됨 개발자가 제품에 합치면 셋째 점이 반영됐어요가 돼요. 반영된 내용은 도구가 스스로 받아 오고, 다음에 만드는 것은 새 작업이에요.

알아 둘 말은 제출과 반영됨, 둘뿐이에요. 저장이라는 말은 없어요 — AI 가 한 차례 답할 때마다 도구가 스스로 그 시점을 보관하고, 작업 기록 서랍에서 언제든 그 시점으로 되돌릴 수 있어요.

안심

안심하고 쓰세요

  • 비밀은 이 컴퓨터에만 연결 코드와 AI 로그인은 맥 키체인 같은 OS 자격 증명 저장소에만 있어요. 공유 서버를 거치지 않아요.
  • 서비스의 원본은 그대로 만든 것은 제출로 개발자에게 가고, 합칠지는 개발자가 정해요. 그 전까지 원본에는 손대지 않아요.
  • 관리자 권한도 터미널도 없이 필요한 도구는 앱이 싣고 와요. AI 프로그램의 설치 · 로그인 · 업데이트도 앱 안에서 끝나요.
  • 한 사람 · 한 컴퓨터 · 하나의 구독 각자 자기 AI 계정으로, 자기 컴퓨터에서 돌려요.

시작하기

세 걸음이면 시작해요

  1. 내려받아 설치하기 릴리스 페이지에서 컴퓨터에 맞는 파일을 받으세요.
    mac (Apple 실리콘) nova-design-<버전>-mac-arm64.dmg Windows nova-design-Setup-<버전>-win-x64.exe

    서명이 없는 배포라 첫 실행에 한 번 허가가 필요해요. Windows 는 SmartScreen 창에서 추가 정보 → 실행, mac 은 시스템 설정 → 개인정보 보호 및 보안 → 확인 없이 열기.

  2. AI 연결하기 첫 화면은 체크리스트 한 장이에요. 화면을 만드는 AI 프로그램(Claude Code)을 설치 버튼 하나로 준비하고, 브라우저에서 내 Claude 계정으로 로그인하면 저절로 돌아와요. Codex 는 선택이라 건너뛰어도 돼요.
  3. 초대 파일 놓기 개발자에게 받은 초대 파일(*.nova-invite)을 첫 화면에 끌어다 놓으면 끝이에요. 셋이 다 채워지면 누를 것 없이 작업 화면이 열려요.

    초대 파일이 아직 없다면 — 개발자에게 이 메시지를 그대로 보내세요.

준비됐어요이제 만들고 싶은 화면을 말씀해 주세요

시작하기 버튼은 없어요 — 셋이 채워지면 작업 화면이 열려요

필요한 것은 mac(Apple 실리콘) 또는 Windows 컴퓨터, 내 Claude 계정, 그리고 개발자에게 받은 초대 파일 하나예요. 업데이트는 앱이 알아서 확인해요 — 켤 때, 앱으로 돌아올 때, 그리고 하루에 한 번.

자주 묻는 질문

궁금한 점이 있나요?

개발을 정말 하나도 몰라도 되나요?

네. 말로 부탁하고, 화면을 찍고, 제출을 누르는 것이 전부예요. 브랜치 · 커밋 같은 개발 용어는 화면 어디에도 나오지 않아요.

우리 서비스를 망가뜨리면 어떡하죠?

작업은 이 컴퓨터에 있는 서비스의 복사본에서만 일어나요. 서비스의 원본은 개발자가 제출을 받아 합치기 전까지 그대로예요. 마음에 안 들면 작업 기록에서 언제든 되돌리면 돼요.

AI 가 엉뚱한 화면을 만들었어요.

말로 다시 고쳐 달라고 하면 돼요. 말부터 다시 하고 싶으면 보낸 말의 고쳐서 다시 보내기, 대화만 되감으려면 ··· → 여기서 새 대화, 화면까지 되돌리려면 작업 기록 서랍에서 그 시점을 고르세요.

오류 화면이 뜨면 어떻게 하나요?

할 일이 없어요. 도구가 화면을 다시 열어 확인하고, 정말 깨져 있으면 AI 가 알아서 고쳐요. 사람의 손이 필요한 건 다시 연결이 필요해요 한 가지뿐이에요 — 새 초대 파일을 놓거나, 브라우저에서 로그인 한 번이면 돼요.

무엇이 필요한가요?

mac(Apple 실리콘) 또는 Windows 컴퓨터, 내 Claude 계정, 그리고 개발자에게 받은 초대 파일 하나. 나머지 도구는 앱이 싣고 와요.

연결 코드와 AI 로그인은 어디에 보관되나요?

OS 자격 증명 저장소(맥 키체인 등)에만 있어요. 공유 서버를 거치지 않고, 화면 쪽 코드에는 절대 전달되지 않아요.

컴퓨터에 무엇이 남나요?

홈의 숨은 폴더 하나 ~/.nova-design/ 가 전부예요 — 설정과 작업 중인 서비스의 복사본. 설정 → 개발자용의 폴더 열기로 열어 볼 수 있어요.

연결 코드가 만료됐다고 나와요.

문제 문장 다시 연결이 필요해요의 초대 파일 열기로, 개발자에게 받은 새 초대 파일을 놓아 주세요. 대화와 보관된 작업은 그대로 남아 있어요.

더 자세한 설명은 사용 설명서에 있어요 — 화면 하나하나, 버튼 하나하나를 적었어요.

개발자라면 팀에 들이는 데 필요한 건 거의 없어요. 서비스의 레포를 연결하는 초대 파일 하나를 만들어 사용자에게 보내면 끝이에요.

  • 설정 파일은 없어요package.json 에 dev 스크립트(없으면 start · serve · preview)와 커밋된 락파일이면 돼요. 포트도 적지 않아요.
  • 결과는 평범한 풀 리퀘스트로 와요nova-design/<날짜>-<번호> 브랜치에서, 본문에 화면 제목 · 경로와 작성자 이름을 적어서. 베이스 브랜치에는 쓰지 않아요.
  • 리뷰는 평소처럼풀 리퀘스트에 코멘트를 남기면 AI 가 반영해 같은 요청에 다시 올려요.
  • 초대는 파일 하나아래 폼이나 node scripts/make-invite.mjs 로 만들어요. 연결 코드는 브라우저 메모리에만 있어요.
  • CLAUDE.md 다섯 줄이면 더 빨라져요화면이 사는 곳 · 라우트 등록 · 목 데이터 · 자주 쓰는 컴포넌트 · 검사 명령.
  • AI 도 못 푸는 문제만 개발자에게 와요열린 요청이 있으면 거기에, 없으면 서비스 쪽 게시판에.

연결 코드를 넣고 레포를 고르면, 고른 레포 전부가 초대 파일 하나에 실려요 — 사용자는 파일을 놓기만 하면 모든 프로젝트가 설정돼요. 내려받은 파일의 내용은 앱만 읽을 수 있게 가려져요(편집기로 열면 알아볼 수 없는 글자로 보여요). 그래도 연결 코드가 들어 있으니 사용자만 보는 경로(슬랙 DM 등)로 보내고, 가져오기가 끝나면 지우라고 안내하세요. 입력한 값은 이 브라우저 메모리에만 두고, 요청은 GitHub 에만 보내요.

    고른 순서가 초대장 순서예요 — 첫 프로젝트가 사용자에게 먼저 열려요.

    문제가 생겼을 때 도구가 개발자를 부르는 길이에요 — 저장소에 알림을 남길 수 있는 연결 코드면 비워도 돼요.

    이메일로 보내기

    이메일은 메일 앱에 초안을 열어요 — 내려받은 파일을 첨부해 보내세요. 공유하기는 OS가 파일 공유를 지원할 때만 나타나며, 슬랙 같은 앱으로 파일을 바로 넘겨요.

    사용자에게 보낼 안내문

      이메일로 보내기의 본문에도 같은 세 줄이 들어가요 — 앱 내려받기 링크 외에는 아무 비밀도 실리지 않아요.

      파일 내용 미리 보기 
      {}

      미리 보기에서는 연결 코드를 가려요 — 내려받은 파일에는 실제 코드가 가려진 봉투 안에 들어 있어요.

      링크로 미리 채우기 · 터미널로 만들기

      이 페이지 주소 뒤에 값을 붙이면 폼이 미리 채워져요. 연결 코드는 주소에 실을 수 없어요 — 주소는 로그와 공유에 남기 때문이에요.

      …/nova-design/?repos=org/a,org/b&reviewers=dev1,dev2&author=김기획#invite

      터미널이 편하면 같은 형식 모듈을 쓰는 생성기가 있어요 — 만들어지는 파일은 같아요.

      node scripts/make-invite.mjs --repo https://github.com/org/a.git \
  --token github_pat_… --author "김기획" --reviewer dev1

      나중에 레포를 더 붙이거나 리뷰어를 바꿀 때도 새 초대 파일을 보내면 돼요 — 사용자는 앱 어디에나 끌어다 놓거나 설정 → 연결 → 초대 파일 열기로 받아요.
